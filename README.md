# Video Conspector

CLI-утилита: скачивает YouTube-видео, распознаёт речь (faster-whisper), читает код с экрана (Tesseract OCR) и строит Markdown-конспект через локальный LM Studio.

## Системные требования (Windows)

1. **FFmpeg** — установлен и добавлен в `PATH` (проверка: `ffmpeg -version`).
2. **Tesseract OCR** с языковыми пакетами `eng` и `rus`. Если `tesseract.exe` не в `PATH`, укажите путь в `.env` (`TESSERACT_CMD`).
3. **LM Studio** с запущенным локальным сервером на порту `1234`. Рекомендуемая модель — `Qwen2.5-Coder-7B`; для AMD RX 9070 XT выберите бэкенд **Vulkan** (стабильнее).
4. **Python 3.10+**.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

## Запуск

```bash
python video_conspector.py --url "https://youtube.com/watch?v=..." --output "./outputs"
```

Дополнительные параметры: `--interval 5` (шаг кадров, сек), `--whisper-model base|small` (по умолчанию `small`), `--keep-temp`, `--no-concepts`, `--no-transcript`.

## Результат

В папке `--output` (её можно указать прямо на хранилище Obsidian) создаётся:

- **Заметка `<Название по смыслу>.md`** — имя берётся из содержания видео, а не из названия ролика. Внутри: свойства (frontmatter: теги, ссылка, канал, длительность, сложность, дата), блок «Кратко», встроенное видео, таблица понятий с `[[вики-ссылками]]`, схема `mermaid`, подробный конспект по частям с таймкодами-ссылками на нужную секунду, код с пояснениями, вопросы для самопроверки (сворачиваемые callout-блоки), задачи `- [ ]` и транскрипт.
- **Папка `Понятия/`** — заметки-заглушки для каждого `[[понятия]]` с обратными ссылками (отключается `--no-concepts`).
- `raw_text.md` — транскрипт и OCR; создаётся, если LM Studio недоступна.

Если код на экране не найден, в заметке появляется предупреждающий callout.

Временные файлы (видео, аудио, кадры) удаляются после обработки.

## Примечания

- Длинные тексты обрезаются до лимитов `MAX_TRANSCRIPT_CHARS` / `MAX_OCR_CHARS` в `config.py`, чтобы уместиться в контекст модели; при необходимости увеличьте контекст модели в LM Studio и эти лимиты.
- Первый запуск скачивает модель Whisper (несколько сотен МБ).

## Известные проблемы

- Если процесс падает с кодом `0xC0000005` при распознавании речи, задайте `WHISPER_VAD=0` в `.env` и используйте версии из `requirements.txt` (закреплены `ctranslate2==4.5.0` и `av==16.0.1`).
- Без установленного Tesseract OCR пропускается, конспект строится только по транскрипту.

## LM Studio: контекст и GPU

Модель нужно загружать с контекстом не меньше 16384 и полной выгрузкой на GPU (бэкенд Vulkan):

```bash
lms load qwen/qwen2.5-coder-14b --context-length 16384 --gpu max -y
```

Если контекст всё же мал, скрипт сам сократит вход вдвое и повторит запрос. Whisper (CTranslate2) не поддерживает AMD GPU и работает на CPU.

Если код на экране не найден, в начало `summary.md` добавляется пометка.
