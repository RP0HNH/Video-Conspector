# Video Conspector

Вставляете ссылку на YouTube — получаете конспект в формате Obsidian: речь (Whisper) + код с экрана (Tesseract) + локальная модель в LM Studio.

Ниже всё по шагам. Команды копируйте **целиком, как есть** (без `<` `>` и без текста `PS C:\...>`).

## Шаг 1. Скачать проект

На странице репозитория: зелёная кнопка **Code → Download ZIP**. Распакуйте архив в **`C:\Video-Conspector`** (не на Рабочий стол и не в OneDrive — там пути с пробелами и русскими буквами, это источник лишних проблем).

## Шаг 2. Установить программы

Нажмите **Win + X → Терминал** (или «Windows PowerShell») и выполните по очереди:

```powershell
winget install Python.Python.3.12
winget install Gyan.FFmpeg
winget install UB-Mannheim.TesseractOCR
winget install ElementLabs.LMStudio
```

- В установщике Tesseract отметьте **Additional language data → Russian** (если не отметить, код будет распознаваться только на английском).
- **Закройте окно терминала и откройте новое**, иначе `ffmpeg` не найдётся.
- Нужен именно Python с python.org (его ставит команда выше), не Anaconda.

## Шаг 3. Настроить LM Studio

1. Откройте LM Studio → поиск → скачайте любую чат-модель (например, **qwen2.5-coder-14b**).
2. Вкладка **Developer** → загрузите модель и поставьте **Context Length от 8192 (лучше 16384)** и **GPU Offload = максимум** (для AMD выберите бэкенд **Vulkan**).
3. Нажмите **Start Server** (порт `1234`).

Программа **сама определяет, какая модель загружена сейчас**, и работает с ней: сменили модель в LM Studio — ничего настраивать не нужно (статус обновляется каждые 8 секунд). Нужную модель можно выбрать и вручную в списке.

Если в LM Studio включена авторизация сервера (Developer → Server Settings), создайте там API-токен и вставьте его в программе: **Настройки → API-токен**.

## Шаг 4. Запустить

**Вариант А (проще всего, без exe):** откройте папку `C:\Video-Conspector` и дважды щёлкните **`run_gui.bat`**. Первый запуск несколько минут ставит пакеты, потом открывается окно.

**Вариант Б (exe):** дважды щёлкните **`build.bat`**. Через 1–2 минуты откроется папка `dist\VideoConspector`. Запускайте **`VideoConspector.exe` только из неё** и только вместе со всей папкой (рядом должна быть папка `_internal`).

> Не запускайте exe из папки `build` или `.pyi_cache` — это недоделанные файлы, будет ошибка про `python312.dll`.

В окне: убедитесь, что вверху зелёная строка «Подключено», вставьте ссылку, нажмите **«Добавить в очередь»**, затем **«Начать»**. Можно добавить несколько ссылок — они обработаются по очереди; во время работы доступна **«Отмена»**. Результат — в папке, указанной в окне (по умолчанию `outputs`; можно указать папку вашего хранилища Obsidian).

## Если что-то не работает

| Что видите | Что делать |
|---|---|
| `Failed to load Python DLL ... python312.dll` | Запущен exe не из `dist\VideoConspector`. Запустите оттуда. |
| «выполнение сценариев отключено» / «нет цифровой подписи» | Не запускайте `.ps1` напрямую, используйте `build.bat` или `run_gui.bat`. |
| `ffmpeg` / `tesseract` не найден | Закройте и откройте терминал после установки; путь к Tesseract можно задать в `.env` (`TESSERACT_CMD`). |
| Красная строка про LM Studio | Запустите сервер (Шаг 3). Без него сохранится только `raw_text.md` (транскрипт и OCR). |
| «LM Studio требует API-токен» | Создайте токен в LM Studio и вставьте в **Настройки → API-токен**. |
| «Ни одна модель не загружена» | Загрузите модель в LM Studio (вкладка Developer) или выберите её в списке. |
| Жёлтая строка «контекст мал» | В LM Studio загрузите модель с Context Length 16384. |
| «HTTP Error 403» при скачивании | Это временный отказ YouTube — просто запустите ещё раз. |
| Другая ошибка | Откройте `video_conspector.log` (рядом с программой) и пришлите последние строки. |

## Настройки (необязательно)

Скопируйте `.env.example` в `.env` (для exe — рядом с `VideoConspector.exe`) и измените нужное: `LM_STUDIO_MODEL` (`auto` — загруженная сейчас), `LM_STUDIO_API_KEY`, `WHISPER_MODEL` (`small` по умолчанию; `base` быстрее, `medium` точнее), `TESSERACT_CMD`.

## Что получается

Заметка с названием по смыслу видео и папка `Понятия/`. Внутри заметки: краткое содержание, ключевые понятия со ссылками `[[...]]`, схема, сжатый конспект только из фактов (без пересказа и воды) с таймкодами-ссылками, код с экрана с пояснениями, вопросы для самопроверки, задачи и транскрипт.

Тесты: `python -m unittest discover -s tests`. Из консоли (для опытных): `python video_conspector.py --url "ССЫЛКА" --output ".\outputs"`.
